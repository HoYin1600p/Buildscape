# Mob Pillar States Configuration
# Format: mob_name|state_name|description

# Universal States (Work on almost any mob)
*|spin|Makes the mob rotate continuously
*|dinnerbone|Renders the mob upside-down
*|grum|Renders the mob upside-down
*|baby|Renders as a baby version
*|glowing|Adds glowing effect
*|fire|Renders on fire
*|frozen|Renders frozen/shaking
*|hurt|Flashes red (damage effect)
*|invisible|Renders completely invisible
